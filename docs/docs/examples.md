# Examples

Ready-to-copy status set setups for common vault structures. Create each as a new status set in Settings, then enable it for the folder that fits.

## Client or project tracking — classic Red / Amber / Green

For a `Projects` or `Clients` folder where you want an at-a-glance read on what's stuck, what's moving, and what's done.

| Order | Label | Color |
|---|---|---|
| 1 | Red | red |
| 2 | Amber | amber |
| 3 | Green | green |

Enable it for `Projects` with **Green** or **Red** as the default, depending on whether new projects usually start blocked or start fine.

## Content pipeline — Draft / In Review / Published

For a `Content` or `Blog Posts` folder, so the file tree doubles as your editorial board.

| Order | Label | Color |
|---|---|---|
| 1 | Draft | gray |
| 2 | In Review | amber |
| 3 | Published | green |

Default new files to **Draft** — every new post starts there until you move it along.

## Reading list — To Read / Reading / Done

For a `Reading List` or `Research` folder.

| Order | Label | Color |
|---|---|---|
| 1 | To Read | blue |
| 2 | Reading | amber |
| 3 | Done | green |

## Personal task board — Todo / Doing / Done

For a `Tasks` folder, or any folder of daily/weekly notes you're tracking progress against.

| Order | Label | Color |
|---|---|---|
| 1 | Todo | gray |
| 2 | Doing | amber |
| 3 | Done | green |

## Sales or outreach pipeline

For a `Leads` folder — one note per lead or opportunity.

| Order | Label | Color |
|---|---|---|
| 1 | New Lead | blue |
| 2 | Contacted | amber |
| 3 | Won | green |
| 4 | Lost | red |

Putting **Lost** last (rather than sorting it with **New Lead**) keeps closed opportunities grouped separately from everything still active, without deleting the notes.

## Mixing status sets in one vault

Nothing stops different folders from using entirely different status sets — a `Clients` folder tracked as Red/Amber/Green sitting right next to a `Reading List` folder tracked as To Read/Reading/Done. Each folder's [assignment](reference/folders.md) is independent.

## Auto-hiding finished work

Take any of the sets above and mark its "done" status — **Green**, **Published**, **Done**, **Won** — as [completed](reference/status-sets.md#completed-statuses) via that status's **"..."** menu. Then turn on **Hide completed** for the folder (Settings, or right-click the folder → **Hide completed items**). Finished items disappear from the sidebar entirely — nothing is deleted, and switching **Hide completed** back off brings them right back.
